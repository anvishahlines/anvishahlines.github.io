# Anvi Stevens Portfolio

Official visual arts portfolio website for Anvi Stevens ([anvistevens.com](https://anvistevens.com)).

## Project Assets & Google Shared Drive
- **Shared Drive Folder**: [Google Drive Folder](https://drive.google.com/drive/folders/1iqonuyovCYynsw9g8_KAONnQP1rhrqwS?usp=sharing)

- React 19 + TypeScript
- Vite
- Tailwind CSS
- Hosted via GitHub Pages with custom domain `anvistevens.com`
